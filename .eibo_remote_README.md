# EIBO — epsilon-indistinguishability brackets for open-set encrypted traffic recognition

This repository develops EIBO, an empirical and theoretical framework for certifying epsilon-indistinguishability brackets in open-set encrypted-traffic recognition, with leakage-aware data splits, reproducible evaluation, and compact experiment artifacts.

## Directory layout

- `src/`: reusable research code
- `scripts/`: command-line experiment and analysis scripts
- `data/`: local data staging, ignored by Git
- `results/`: smoke tests and experiment outputs, ignored by Git
- `logs/`: runtime logs, ignored by Git
- `artifacts/`: environment locks and setup reports
